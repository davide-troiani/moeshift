# Security

Report suspected vulnerabilities privately to the maintainer at
**security@davidetroiani.it**. Include the affected revision, reproduction steps and
relevant logs. Do not post exploit details in a public issue before a fix can
be discussed. Response times depend on maintainer availability.

MoEShift serves localhost only and does not require authentication. Do not
expose it through a public proxy. Use trusted model files and review client
applications before granting them access to private data.

Report ordinary installation and inference bugs through the GitHub issue forms.
